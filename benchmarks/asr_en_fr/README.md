# English/French ASR benchmark corpus

## Sample types

- **Synthetic (current manifest):** Piper TTS read-aloud WAVs generated by `scripts/prepare_asr_benchmark_clips.py`. Useful for repeatable WER baselines and latency smoke tests; **not** conversational speech quality.
- **Natural (recommended):** See [NATURAL_CORPUS.md](./NATURAL_CORPUS.md). Use `sample_type: natural` plus `license` and verified `reference_text`.

## Prepare synthetic clips

```powershell
py -3.12 -m venv .venv-asr312
.\.venv-asr312\Scripts\python.exe -m pip install -r requirements.txt
.\.venv-asr312\Scripts\python.exe -m pip install -r requirements-asr-whisper.txt
.\.venv-asr312\Scripts\python.exe scripts/prepare_asr_benchmark_clips.py
```

## Run benchmark

Default faster-whisper model is **`small`** (CPU `int8`, multilingual EN/FR). Override with `--model` or `MWIZERWA_WHISPER_MODEL`.

```powershell
.\.venv-asr312\Scripts\python.exe scripts/benchmark_whisper_asr.py --co-residency -o benchmarks/asr_en_fr/results_whisper_small.json
```

Results are **local measurements only**; synthetic Piper clips do not establish conversational accuracy. Older `results_large_v3_turbo.json` is a prior large-model run, not the active default.

### Co-residency (16 GB machine)

Use the **API `.venv`** with both stacks:

```powershell
.\.venv\Scripts\pip install -r requirements-asr-whisper.txt
.\.venv\Scripts\python.exe scripts/benchmark_coreidency_llm_whisper.py -o benchmarks/asr_en_fr/results_coreidency.json
```

Separate subprocess phases measure LLM-only, Whisper-only, and **sequential** dual-resident inference (not concurrent).
